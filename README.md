A faster drop-in for make.fun's own makefun-site 1.0.0: `solve.js` answers exactly as makefun-site does on every case, in far less CPU time. One architecture, three levers: a single-pass direct Markdown renderer (no token objects), templates compiled once to JavaScript functions instead of tree-walking interpretation, and hand-rolled fast text primitives (HTML escape, slugify with an ASCII fast path and a per-case cache, front-matter scanning without splitting the body).
